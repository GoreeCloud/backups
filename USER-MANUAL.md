# GoreeCloud Backups — User Manual

**Status:** Pre-implementation user manual  
**Last Updated:** 2026-09-24

## Availability

GoreeCloud Backups is not currently verified as an implemented or released application in this repository.

There is therefore no supported backup, restore, repository, or recovery workflow available to document as operational user functionality yet.

## What This Manual Will Cover

As features become implemented and validated, this manual is expected to document:

- Installation and first-run setup.
- Creating or opening a repository.
- Recovery credentials and safe storage.
- Adding protected sources.
- Creating and applying protection policies.
- Scheduling backups.
- Viewing backup status.
- Browsing snapshots.
- Planning a restore.
- Restoring files, directories, applications, and systems.
- Running repository verification.
- Running restore tests.
- Understanding protection states and recovery evidence.
- Managing retention and maintenance.
- Configuring repository storage.
- Managing agents and multiple protected systems.
- Privacy, security, and destructive-operation safeguards.
- Clean-environment disaster recovery.
- Diagnostics and recovery troubleshooting.

## User-Safety Rule

The manual must never describe a planned function as available before the corresponding implementation and validation evidence exists.
